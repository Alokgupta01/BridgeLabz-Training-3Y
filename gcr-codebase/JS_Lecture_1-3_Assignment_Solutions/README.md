# JavaScript Assignment 1 (Lectures 1–3)

This folder contains solutions for all 10 questions in the assignment PDF. Each question has a separate JavaScript file, with comments and beginner-friendly formatting. The solutions use core JavaScript only.

## Questions

1. Personalized Login Greeting
2. Multi-Type Data Summary
3. Monthly Expense Tracker
4. Academic Performance Evaluator
5. Weather Activity Planner
6. Progressive Discount System
7. Smart Guessing Game
8. Employee Salary Projection
9. Random Math Quiz Generator
10. Citizen Eligibility Validator

## Run a solution

Open a terminal in this folder and run a file with Node.js, for example:

```bash
node Q1_Personalized_Login_Greeting.js
```

Use the matching filename to run another question. Change the sample values in each file to test different outcomes. Randomized questions and greetings may produce different results depending on the current time or generated values.
