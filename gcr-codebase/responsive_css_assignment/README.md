# Responsive CSS Assignment 9

This folder contains the HTML and CSS solutions for all 10 questions from the provided assignment.

- One HTML and one CSS file are provided for every question.
- No JavaScript or external CSS framework is used.
- Layouts use CSS Flexbox/Grid and media queries.
- The files use simple, readable HTML and CSS suitable for a student assignment.

Open any HTML file in a browser to view the corresponding question.
