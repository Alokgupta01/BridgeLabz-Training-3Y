# JavaScript Operator Assignment (Questions 1–10)

This repository contains my solutions to all 10 questions from the JavaScript assignment. I kept each question in a separate `.js` file, added comments to explain the main logic, and used plain JavaScript without external libraries.

## Files

- `Q1_Scope_Conflict_Resolver.js` — global and local scope
- `Q2_String_Manipulation_Report.js` — string cleanup and formatting
- `Q3_Math_Utility_Dashboard.js` — Math methods and template literals
- `Q4_Array_Performance_Analyzer.js` — random scores and array methods
- `Q5_Boolean_Logic_Access_System.js` — Boolean operators and security checks
- `Q6_Event_Based_Counter_Simulation.js` — functions and nested scope
- `Q7_Customer_Feedback_Processor.js` — feedback checks and word count
- `Q8_Dynamic_Discount_Evaluator.js` — category and cart discounts
- `Q9_Odd_Even_Number_Analyzer.js` — number classification from 1 to 30
- `Q10_Departmental_Employee_Evaluator.js` — department performance ratings

## How to run

1. Install Node.js if it is not already installed.
2. Open a terminal in this folder.
3. Run any question separately, for example:

   ```bash
   node Q1_Scope_Conflict_Resolver.js
   ```

4. Replace `Q1` with the filename of the question you want to test.

Some results, such as random scores and random numbers, will be different each time the program runs.

## Notes

- Each question has its own JavaScript file, as requested.
- The code uses readable variable names and comments.
- No external libraries or frameworks are required.
